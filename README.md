# 个人 AI 操作系统 · Personal AI OS

> 让任何 AI 按同一套书面协议，持续打理你的 Obsidian 人生系统：日报、台账、周复盘、观点验证——数据不撒谎，AI 必须反驳你。

协议是纯文本，不锁任何平台：Claude、GPT、Gemini、豆包、DeepSeek 都能接管。你的数据始终在自己电脑上。

## 为什么大多数"自律系统"会死

1. **清单变空壳**——设计越精密，填写越稀少。重构到 v6 的那个晚上，勾选恰好归零。
2. **元工作挤占执行**——深夜重构系统的快感，完美替代了真实做事。
3. **AI 顺从性**——你说什么它都对。没有反驳的参谋，等于没有参谋。

本模板不靠意志力解决这三个问题，靠结构：规则书面化、感觉数据化、反驳义务化。

## 四块基石

| 基石 | 文件 | 一句话 |
| --- | --- | --- |
| 协议先行 | `vault/90 AI/10 规则/AI 协作协议-模板.md` | AI 不猜规则：权限、流程、禁做清单全部书面化 |
| 台账先行 | `vault/30 个人/台账/台账-模板.md` | 感觉不可信，数据说话：睡眠、运动、消费、任务各立台账 |
| 观点验证 | `prompts/03-观点验证.md` | 新观点一律 [待验证] + 检验方式 + 回访日期，到期拿数据裁决 |
| 日清流程 | `prompts/01-启动会话.md` | 每次会话固定五步，最后一句话回报 |

## 安装方式（三选一，都免费）

| 方式 | 适合谁 | 步骤 | 用时 |
| --- | --- | --- | --- |
| **① 一键安装（推荐）** | Windows | [下载 ZIP](https://github.com/Jingangster/personal-ai-os/archive/refs/heads/main.zip) → 解压 → 双击 `install.bat` → 选编号 → 完成。**没装 Obsidian 会自动静默装好** | 2–5 分钟 |
| **② AI 带装** | 已在用 AI | 把 [工作模式提示词](prompts/00-工作模式.md) 全文粘贴给任意 AI，它带你装完 | 2–10 分钟 |
| **③ 手动** | Mac / Linux | 下载 ZIP 解压，把 `vault/` 三个文件夹拖进 Obsidian 库；或终端跑 `bash install.sh` | ~5 分钟 |

> 国内直连 GitHub 打不开？在下载链接前面加 `https://ghfast.top/`（即 `https://ghfast.top/https://github.com/Jingangster/personal-ai-os/archive/refs/heads/main.zip`）；仍失败就换前缀 `https://gh-proxy.com/` 或 `https://ghproxy.net/`。

> 完全没接触过 Obsidian 或 AI？先看 **[小白指南](docs/小白指南.md)**——从装软件开始教，不写代码，30 分钟跑通。

## 3 天接入

**Day 1 · 安装**
把 `vault/` 下的模板复制进你的 Obsidian 库（保持目录名），填 `90 AI/00 从这里开始-模板.md` 的身份页——只填三行：你是谁、主线目标、底线。

**Day 2 · 接管**
打开任意 AI 对话，粘贴 `prompts/01-启动会话.md` 全文。它会先读协议，再跑第一次日清，最后一句话向你回报。

**Day 3 · 砍掉**
删掉你用不上的模块。协议是起点不是枷锁——每一条都遵循同一原则：**不同意就删，删除不影响系统其余部分运行**。

## 设计原则

- **数据不撒谎**：台账只记真实值；没记录就是没发生，不补记、不估算。
- **不代写**：AI 只教、只给检查清单、只改格式；作业、论文、报告自己写。
- **先完成再完美**：总结写不完就写三行——空白表格比烂表格更浪费。
- **防复发**：任何系统重构 3 天上限；第 4 天还没回到正事，就归档重构念头。
- **用户消息优先**：人发来的消息永远排在系统流程前面。
