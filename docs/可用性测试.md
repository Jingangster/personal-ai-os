# 可用性测试：用 5 个真实用户定位"到底哪一步难"

> 背景：开发者觉得"对用户还是太难"。这是感觉，不是数据。本脚本把它变成一次 1 小时内可完成的实验。

## 找谁（3–5 人，就够）

符合画像即可，**不要找程序员、不要找用过 Obsidian 的人**：

- 大学生 / 年轻上班族，会用微信、抖音
- 手机或电脑上装过豆包 / DeepSeek / Kimi 至少一个（问一句"你用过 AI 聊天吗"即可筛）
- 没见过这个项目的任何介绍

来源就选你身边：舍友、同学、群友。**舍友是最好的第一个**——失败了成本为零。

## 怎么测（铁律：只观察，不帮忙）

发这句话术：

> 我做了个东西，你帮我装一下呗。你边做边说你在看什么、在想什么就行——**就算卡住我也不会帮你**，这是测试规矩。

然后坐在旁边（或远程屏幕共享），全程闭嘴，只记录：

| # | 步骤 | 卡壳人数 | 平均耗时 | 参与者原话（记原话，别意译） |
| --- | --- | --- | --- | --- |
| 1 | 打开下载链接 |  |  |  |
| 2 | 下载 ZIP |  |  |  |
| 3 | 解压 |  |  |  |
| 4 | 双击 install.bat（含 SmartScreen） |  |  |  |
| 5 | 黑窗口选编号 |  |  |  |
| 6 | 等待安装完成 |  |  |  |
| 7 | 找到并复制提示词（剪贴板/弹窗） |  |  |  |
| 8 | 粘贴给 AI 并发送 |  |  |  |
| 9 | 跟着 AI 完成第一次对话 |  |  |  |

## 测完三问（每人必答）

1. 刚才哪一步你最不确定自己在干什么？
2. 你觉得自己装成功了吗？
3. 明天你会主动打开它吗？（诚实说）

## 判定规则（提前定死，防事后找补）

- 某一步 **≥2 人卡壳** → 改那一步，改完重测
- 卡壳集中在**链接打不开** → 换网盘直链为主，加速链接为辅
- 卡壳集中在 **SmartScreen** → 宣传物料里把这张图放在第一屏
- **≥2 人答"明天不会打开"** → 这不是安装问题，是产品价值问题，回筛选器重审
- **≤1 人卡壳、≥3 人答"会"** → "太难"判定废止，把火力转去分发

## 测完之后

把判定结果写进观点库对应条目（[待验证]「对用户还是太难」），数据是什么就是什么——包括"感觉错了"这个结果。
