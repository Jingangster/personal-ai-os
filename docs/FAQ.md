# FAQ

**Q：必须用 Obsidian 吗？**
不必须，但模板按 Obsidian 设计（本地 Markdown + 双链）。任何能编辑 Markdown 文件的环境都能用，包括 VS Code。

**Q：用哪个 AI 最好？**
都能用。协议是纯文本，AI 只需要能读长文并按步骤执行。判断标准很简单：它肯不肯先读协议再干活，肯不肯反驳你。不肯的，换。

**Q：数据安全吗？**
所有文件在你自己电脑上。AI 只在你主动粘贴内容或授权工具访问时才读到数据。密码、密钥类文件建议协议禁读（模板已内置）。

**Q：我没有那么多要管理的，值得上这套系统吗？**
砍着用。最小可用集 = 首页 + 睡眠台账 + 观点库。三样就够了：今天做什么、睡了几个小时、哪些想法等验证。

**Q：会不会变成"做系统而不做事"？**
会——如果你不做防复发。所以铁律里写了：重构 3 天上限，第 4 天回正事；先完成再完美，空白表格比烂表格更浪费。

**Q：任务老是完不成，怎么办？**
先看是不是清单太重。连续 7 天零勾选 → 砍半。还不行 → 砍到只剩 1 条。1 条都完不成的，那条任务不是任务，是愿望，重写成"动词+对象+数量/时间"再试。

**Q：观点库和决策日志有什么区别？**
观点库放"我认为"（等数据裁决）；决策日志放"我决定了"（记当时的依据，回访看后果）。一个是认知，一个是行动。

**Q：AI 每次会话都要重新读协议，会不会很费 token？**
会有一点。比它便宜的是：规则不用每次口头重复，且每次执行一致。如果你用支持项目知识/自定义指令的 AI 工具，把协议放进那里，成本更低。
