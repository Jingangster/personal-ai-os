# 台账模板包

> 用法：下面每个小节复制成一个独立 .md 文件，放进 `30 个人/台账/`。
> 原则：只记真实值；没数据就留空，不补记、不估算。空行连续多天 = 执行断流，周复盘如实报告。

## 二、思考台账

### 观点库.md

> 每条标注状态。回访日拿数据裁决：转正 / 修正 / 废止（废止不删除，留档）。

- [待验证] 【观点】。检验：【方式】。回访：【日期】。
- [已确认] 【观点】（依据：【数据/事件】）
- [已废止] 【观点】——【废止原因 + 日期】

### 决策日志.md

> 每个重要决定记一条。"当时的数据"比"现在的后悔"更有用。

| 日期 | 决定 | 理由（数据/依据） | 结果回访 |
| --- | --- | --- | --- |
|  |  |  |  |
